# 恒大／许家印案件资料汇总网页

这是可直接部署到 GitHub Pages 的静态网站包。

## 部署方法

1. 在 GitHub 新建一个公开仓库。
2. 将本目录中的全部内容上传到仓库根目录。
3. 确认网页文件名为 `index.html`，不要改名或移动“文献”文件夹。
4. 在仓库的 **Settings → Pages** 中选择 **Deploy from a branch**。
5. 选择默认分支和 `/ (root)` 目录并保存。

网页中的学术文献链接使用相对路径，因此 `index.html`、`文献`文件夹和 `学术参考文献附件.zip` 必须保持在同一层级。

网页内容仅为公开资料整理和研究辅助，不构成法律意见。
